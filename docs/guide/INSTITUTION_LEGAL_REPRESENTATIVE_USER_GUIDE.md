# 机构法人用户指南 / Institution Legal Representative Guide

本指南面向希望在悦享平台申请机构法人身份的普通用户。完成注册后，用户可以提交法人认证；平台审核通过后，账号会保留普通用户功能，同时获得对应机构的专业管理能力。

机构法人身份不等于平台管理员身份。法人只能管理与本人已确认关联的机构，不能进入平台管理后台或管理其他机构。

## 一、申请前准备

申请前请确认：

- 已注册并登录悦享用户端；
- 申请人确为机构法定代表人，并有权提交机构及个人认证信息；
- 真实姓名、证件号码、机构名称、统一社会信用代码、地区和地址准确一致；
- 已准备清晰、完整且在有效期内的认证材料；
- 已准备一个真实、可联系的联系电话。

请勿使用他人资料、模糊图片、过期证件或与申请机构无关的材料。

## 二、需要填写的信息

| 信息 | 填写说明 |
|---|---|
| 真实姓名 | 填写法定代表人的真实姓名，应与身份证件一致 |
| 证件号码 | 填写法定代表人的有效证件号码 |
| 联系电话 | 由申请人自行填写，可填写本人或机构实际使用的手机号、座机等联系方式 |
| 机构名称 | 填写营业执照上的机构完整名称 |
| 统一社会信用代码 | 按营业执照准确填写 |
| 所在地区 | 填写机构所在省、市或地区 |
| 详细地址 | 填写机构实际经营地址 |

### 联系电话说明

- 联系电话不会自动使用注册手机号，申请人需要自行填写；
- 联系电话可以与注册、登录账号的手机号不同；
- 建议填写能够正常接听、适合对外联系的机构电话，并根据需要包含国家码或区号；
- 审核通过后，该号码会作为机构档案的初始联系电话，可能展示在机构公开页面；
- 法人可在“专业管理 → 机构档案”中修改机构联系电话；
- 修改机构联系电话不会修改账号的注册手机号或登录方式。

## 三、需要上传的材料

申请机构法人身份必须上传以下三类材料：

1. 营业执照；
2. 身份证人像面；
3. 身份证国徽面。

上传要求：

- 支持 JPG、PNG、WebP 和 PDF；
- 单个文件不超过 10 MB；
- 图片文字、证件边缘和关键信息应完整清晰；
- 材料中的姓名、证件号码、机构名称及统一社会信用代码应与申请表一致；
- 认证材料仅用于平台审核，不会作为公开图片显示在机构主页。

## 四、提交法人认证

1. 登录用户端，进入底部导航“我的 / Profile”；
2. 点击“身份认证 / Identity verification”；
3. 点击“申请专业身份 / Apply for a professional identity”；
4. 选择“机构法人 / Institution legal representative”；
5. 依次填写申请人和机构信息；
6. 上传营业执照、身份证人像面和身份证国徽面；
7. 检查所有内容无误后，点击“提交审核 / Submit for review”。

提交成功后，申请记录会显示“审核中 / Under review”。审核中的申请不能重复提交，已提交的认证材料也不能作为未提交草稿删除。

## 五、查看审核结果

进入“我的 → 身份认证”，展开“申请记录”即可查看状态。必要时可下拉刷新或重新进入页面获取最新结果。

| 状态 | 说明 | 后续操作 |
|---|---|---|
| 审核中 | 平台正在核验资料 | 等待审核，不要重复提交 |
| 已通过 | 法人身份认证成功 | 进入专业管理，检查机构档案和管理权限 |
| 未通过 | 资料不完整、不一致或不符合要求 | 查看审核说明，修正信息和材料后重新申请 |
| 已撤销 | 法人专业身份已被平台撤销 | 无法继续使用对应管理权限，如有疑问请联系平台客服 |

审核通过后，账号的普通用户功能不会受到影响。系统会激活机构法人专业身份，并关联本人可管理的机构；如果此前没有法人机构关系，系统会根据申请资料创建初始机构档案。

## 六、认证通过后的首次检查

审核通过后建议完成以下检查：

1. 进入“我的 → 身份认证”，确认“机构法人”显示为“已认证”；
2. 返回“我的”，进入“专业管理 / Professional management”；
3. 确认页面出现“法人 / Legal representative”分组；
4. 打开“机构档案 / Institution profile”；
5. 核对机构名称、地区、地址、联系电话和资质信息；
6. 完善营业时间、机构介绍、标签、擅长领域及公开图片；
7. 点击“保存档案”，重新进入页面确认内容已保存。

如果账号关联多个可管理机构，进入机构档案后需要先选择要维护的机构。

## 七、机构档案与公开信息

机构档案用于向普通用户公开展示。以下信息可能出现在机构相关页面：

- 机构名称、城市和地址；
- 联系电话和营业时间；
- 机构介绍、标签和擅长领域；
- 封面图、环境图片和公开资质图片；
- 平台认证状态及其他公开业务信息。

请勿在机构档案中填写身份证号码、个人住址、内部管理信息或其他不应公开的隐私资料。身份证件和营业执照应通过法人认证的私有材料入口提交，不要作为机构公开图片重复上传。

## 八、法人可使用的管理能力

实际入口会根据账号的有效身份、机构关系和平台配置显示。常见能力包括：

- 查看专业目录；
- 查看和维护本人管理的机构档案；
- 审核医生、医美顾问与本机构的关系申请；
- 审核本机构相关的项目申请或加入申请；
- 查看平台为该机构开放的其他专业管理功能。

没有显示的功能代表当前账号尚无对应权限。机构法人不能通过“机构关系”页面自行加入其他机构，也不能管理未与本人确认关联的机构。

## 九、常见问题

### 1. 为什么无法再次申请机构法人？

账号可能已有审核中的法人申请，或已经拥有有效的机构法人身份。请先在“申请记录”中确认当前状态。

### 2. 联系电话必须与注册手机号一致吗？

不需要。联系电话由申请人自行填写，用于机构联系和初始机构档案；注册手机号用于账号登录。两者可以不同，修改机构联系电话也不会改变登录手机号。

### 3. 为什么材料上传失败？

请确认文件类型为 JPG、PNG、WebP 或 PDF，单个文件不超过 10 MB，并检查网络连接及系统的相册或文件访问权限。

### 4. 审核通过后为什么看不到法人管理入口？

请先刷新身份认证页面，再重新进入“专业管理”。仍未显示时，可以退出后重新登录；如果机构档案提示“当前账号暂无可管理机构”，请联系平台客服核查法人身份和机构关系是否都已生效。

### 5. 审核未通过后可以重新申请吗？

可以。请先阅读审核说明，修正不一致的信息或重新准备清晰材料，然后创建新的法人申请。

### 6. 认证材料会公开吗？

不会。法人认证材料通过私有审核通道保存，仅供授权审核人员核验。机构档案中的公开图片和文字属于另一类信息，请自行确认适合公开展示。

## 十、信息变更与安全建议

- 机构联系电话、地址或公开资料发生变化后，请及时更新机构档案；
- 法定代表人、营业执照或主体信息发生重大变化时，请联系平台确认是否需要重新认证；
- 不要向无关人员提供账号密码、验证码或认证材料；
- 使用公共设备后请及时退出账号；
- 如发现身份被错误撤销、机构关联异常或资料疑似泄露，请立即联系平台客服。
