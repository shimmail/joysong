# Joysong App 正式落地 MVP 功能规格

> 文档版本：1.1
> 基线日期：2026-08-29
> 发布目标：面向美国地区上架 Android 与 iOS，服务发生地为中国
> 生产数据部署目标：后端、数据库和身份材料私有存储均位于中国大陆；当前尚无已部署、可验证的生产环境证据
> 发布定义：应用商店正式分发、真实用户、真实数据、真实支付
> 需求依据：已确认的产品决策、当前代码及 2026-08-29 多 Agent 复核
> 明确排除：doc/娇颜颂需求.pdf 已过时，不再作为需求或验收依据

## 1. 文档目的

本文档规定 Joysong 首发 MVP 应提供的功能、明确不提供的功能、当前代码完成度和正式发布门槛。产品、开发、测试和运营均以本文为首发范围基线。

当历史文档或当前代码与本文冲突时：

1. “预期功能”以本文和已确认产品决策为准；
2. “当前状态”以可定位的代码和可复现的验收证据为准；
3. 已存在但超出 MVP 的入口应隐藏，不能因代码存在而自动纳入首发；
4. 未经确认的功能不得补充为产品承诺。

## 2. MVP 完成定义

### 2.1 发布层级

| 层级 | 定义 | 对外表述 |
|---|---|---|
| 正式落地 MVP | 美国地区应用商店正式分发；处理真实账号、身份材料和业务数据；使用真实 Alipay+ 收款和退款；生产安全、运维及合规材料完成 | 可以正式上线 |
| 受邀试点 | 受控账号和规模；关闭真实在线收款；限制敏感数据；人工运营兜底 | 仅限受邀试点 |
| 开发演示 | 测试数据、模拟支付、开发配置 | 仅用于开发或演示 |

### 2.2 优先级和状态

- MUST：正式上线前必须完成并验证，任一未完成均可阻断发布。
- SHOULD：不阻断核心闭环，但未完成时必须隐藏入口或提供明确降级。
- OUT：不属于首发 MVP，不得对用户展示或承诺。

当前状态使用以下定义：

- 已实现待验收：已有真实代码链路，但尚无生产等价环境的完整证据。
- 部分实现：仅完成部分链路，或当前行为与 MVP 规则不一致。
- 未实现：不存在可用链路。
- 外部依赖未完成：依赖商户、短信、证书、域名、应用商店账号等外部条件。
- 已验证：已在生产等价环境通过验收并保存证据。

页面存在、开发环境模拟成功或历史测试通过，都不等于“已验证”。

## 3. 产品边界

### 3.1 用户、服务与数据地域

| 项目 | 首发范围 |
|---|---|
| 用户来源 | 美国 |
| 应用上架地区 | 美国 |
| 客户端 | Flutter Android App、Flutter iOS App |
| 服务发生地 | 中国 |
| 业务时间基准 | 北京时间 UTC+8 |
| 生产后端 | 中国大陆 |
| 生产数据库 | 中国大陆 |
| 身份材料私有存储 | 中国大陆 |
| AI 服务 | 允许由位于中国大陆的第三方大模型服务商处理限定数据 |
| 平台管理 | 独立 React Web 管理后台，不进入 Flutter App |

面向美国用户、在中国大陆处理和存储数据所需的隐私披露、跨境数据说明、供应商协议和适用法律审查，必须在发布前由具备资质的专业人员确认。本文不替代法律意见。

### 3.2 商业和支付边界

平台首发只在线收取以 USD 计价的旅游地接服务费：

- 用户通过 Alipay+ 支付；
- 医疗费用由用户到院后直接向医院支付；
- 平台不代收医疗费用；
- 不提供医疗分账、余额、钱包或提现；
- 不启用 Stripe 新支付链路；
- 不提供咨询费、面诊金或医疗尾款在线收取。

### 3.3 Flutter App 角色

所有用户和专业身份均在同一个 Flutter App 中申请并查看审核结果。机构法定代表人和医生使用现有专业工作台；顾问订单工作台是首发 MUST，但当前尚未实现。

| 角色 | 首发职责 |
|---|---|
| 游客 | 浏览允许匿名访问的公开目录、公开内容、分享页和法律文档 |
| 普通用户 | 注册登录、浏览发现、AI 咨询、真人咨询、预约下单、支付、订单会话、退款、评价、内容互动和账号管理 |
| 医美顾问 | 当前可维护有效机构关系和浏览项目目录；“查看本人订单并回复订单会话”是待补齐的首发 MUST |
| 医生 | 维护专业资料和机构关系；申请或维护授权项目；查看当前权限允许的专业订单 |
| 机构法定代表人 | 维护本人机构资料；审核机构成员关系和项目协作请求 |

首发范围不包含“机构客服”身份、申请或工作台；当前管理端和服务端仍保留该角色，发布前必须移除其管理端入口，并在服务端拒绝新建、审核或激活。其咨询职能由医美顾问承担。顾问不发起“服务已完成”请求。平台管理员继续使用独立 Web 管理后台。

## 4. 核心用户闭环

首发 MVP 必须支持以下完整流程：

> 使用美国 +1 手机号注册或找回密码 → 手机号和密码登录 → 浏览项目、机构、医生和内容 → AI 问答或转接真人顾问 → 选择项目、医生、有效机构顾问及预约时间 → 创建订单 → 支付 USD 旅游地接服务费 → 顾问资料和订单专属会话开放 → 顾问提供订单服务 → 用户确认完成或系统自动完成 → 用户评价。

发生退款时：

> 用户在订单完成前申请整笔退款 → 平台人工审核 → Alipay+ 原渠道退款 → 订单会话保留为只读。

### 5.10 账号注销和数据处理

账号注销必须遵守以下确定流程：

1. 用户在 App 内提交注销；
2. 系统检查进行中的订单、支付、退款、拒付和争议，以及已有专业身份；
3. 存在任一阻断事项时，立即拒绝本次注销并展示具体原因；
4. 被拒绝的注销申请不保存、不自动继续，也不提供“撤销注销申请”；
5. 用户处理完全部事项后必须重新提交；
6. 专业用户必须先完成专业身份注销审核并解除机构关系；
7. 无阻断事项时，立即永久注销账号并执行数据清理。

| 手机号、邮箱、密码、昵称、头像、证件和个人资料 | 永久删除或不可逆擦除 |

| AI 会话及相关用户数据 | 删除 |

| 已完成订单评价 | 匿名保留为“已注销用户” |
| 普通评论 | 匿名保留为“已注销用户” |
| 用户日记及日记图片 | 删除 |
| 点赞、收藏和历史关注关系 | 清除 |

## 6. 明确不属于首发 MVP

6. 私信、订单会话和专业身份内容的第三方大模型翻译；
7. 医生或机构排班、可预约时段库存和预约冲突检测；
8. 支付后修改预约时间；
9. 部分退款、自动退款和订单完成后的退款；
10. 平台代收医疗费用、医疗分账、钱包和提现；

12. LEGACY_MEDICAL 新订单创建；
13. 群聊、音视频、直播和复杂社交关系；

15. 航班、酒店和护照行程备案；

遗留数据的安全查询、退款、争议和法定义务不因功能退出首发而消失，但不能成为新用户可用入口。

## 7. 安全、部署和发布门槛

### 7.1 安全与数据

正式处理真实用户和身份材料前，必须完成：

1. 所有公网通信使用 TLS；正式客户端只允许生产 HTTPS API 和受信任跳转域名；
2. 身份材料迁移到中国大陆私有对象存储，使用加密/KMS、短期授权 URL、最小权限、访问审计和可验证删除；
3. Token、验证码、证件、聊天和支付数据不得进入普通日志；
4. AI 调用在服务端执行数据分类和字段白名单，禁止私信、订单私密信息、身份和资金数据外发；
5. 验证码、登录和敏感接口使用共享限流状态，覆盖手机号、IP、设备和全局维度；
6. 管理端身份、隐私和资金操作执行最小权限及不可篡改审计；
7. 密钥不进入仓库，生产启动时拒绝开发默认值和缺失配置；
8. 完成适用于美国用户、中国服务和中国大陆数据处理路径的专业法律与安全审查。

- 项目、机构、医生、顾问、发现和订单目录已有真实接口；

- 日记、评论、点赞、收藏、分享、私信、举报和站内通知已有实现；
- 账号注销、法律文档管理和公开法律页面已有代码基础；
- 管理端身份、内容、订单和退款操作已有较广覆盖。

### 9.2 正式落地 P0

1. 真实 Alipay+ 网关、退款和对账尚未接通；
2. 身份材料仍缺生产私有对象存储、加密/KMS、短期授权和审计；
3. AI 数据边界与当前私信/订单自动翻译冲突，且版本化同意、保留和第三方删除未闭环；
4. 美国 +1 短信只有格式兼容，真实投递和共享限流未验证；
5. 顾问缺少本人订单工作台，无法形成已确认的客服履约闭环；创建订单也缺少幂等去重；
6. 预约满 30 天自动完成未实现，当前代码允许完成后退款，且遗留任务会自动评价并进入 PENDING_SETTLEMENT；
7. 账号注销在生产环境硬关闭，专业身份退出和站外删除入口未完成；
8. 中国大陆生产部署、TLS、私有存储、监控、备份、回滚和密钥管理无执行证据；
9. Android 正式签名、iOS Archive/TestFlight、双端真机及美国商店资料未完成；
10. 举报账号、拒付/争议、异常扣款管理端和关键操作审计未形成运营闭环。

### 9.3 判定

| 目标 | 当前结论 | 原因 |
|---|---|---|
| 正式落地 MVP | No-Go | 资金、安全、隐私、核心履约和发布 P0 尚未关闭 |
| 关闭收款的受邀试点 | Conditional Go | 仅可使用受控账号、限定规模、限制敏感数据并由人工运营兜底 |
| 开发演示 | Go | 可使用测试数据和明确隔离的模拟能力，不得宣称正式上线 |
