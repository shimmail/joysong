# 简历项目经历

## 娇颜颂（JoySong）医美服务平台｜全栈开发（AI Agent / Vibecoding）

**2026.07 - 至今**

**项目简介：** 娇颜颂是一个面向用户、医生、机构和平台运营人员的医美服务平台，包含 Flutter Android/iOS 双端、React 管理后台和 Kotlin/Spring Boot 服务端，覆盖医美内容发现、AI 咨询、预约订单、支付退款、消息客服等业务。

**技术栈：** Kotlin、Spring Boot 3、MySQL、Spring Security/JWT、OpenAI API、Flutter/Dart、React + TypeScript。

- 负责服务端、Flutter Android/iOS 双端和 React 管理后台协同开发，打通认证、内容发现、预约订单、支付退款和消息客服等核心链路。
- 设计医美 AI Agent，支持意图路由、多轮上下文、机构/医生/项目检索、对比报告、方案规划和安全筛查；为 LLM 非法输出、超时等异常设计可控回退。
- 服务端按领域拆分 45 个 Controller，统计约 230 个 REST 接口；Flutter 端按 feature + data/domain/presentation 分层组织业务代码。
- 主导 Vibecoding 开发流程：负责明确业务边界、拆解领域任务、设计 API/数据模型、编写约束性提示词，并让 AI 辅助生成实现、测试和文档；对关键逻辑进行人工审查、取舍和重构。
- 以编译、单元测试和回归测试验收 AI 产出，当前服务端配套 23 个测试类/模块，覆盖 Agent 路由、支付、发现、认证等关键逻辑，并维护 OpenAPI、开发文档和测试指南。
