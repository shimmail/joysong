# 机构法人核心链路手工联调测试

最后更新：2026-08-29

统一环境、账号准备、跨角色执行顺序、通用权限断言和通过门槛以[全角色最小联调测试总流程](README.md)为准。本分册只保留机构法人独有的最小成功链路，不重复普通用户、管理员、医生、顾问和订单通用测试。

相关用户说明：[机构法人用户指南](../guide/INSTITUTION_LEGAL_REPRESENTATIVE_USER_GUIDE.md)。

## 1. 范围与职责

本轮只验证：

`L-01 提交法人申请 → A-01 批准 → 原子初始化 I-01/法人任职/机构钱包 → L-01 编辑机构档案 → U-01 查看公开页 → L-01 批准 D-01/C-01 JOIN → L-01 批准 IPJ-01`

角色边界：

- 法人身份申请由平台管理员批准；批准后基础平台角色仍为 `USER`，不获得平台管理员权限；
- 法人只能管理 `managedInstitutionIds` 中的机构，并审核该机构的关系和项目申请；
- 医生、顾问本人发起 `JOIN`，目标机构法人审核；
- 已生效专业身份的撤销只由平台管理员执行，不属于本次最小链路；
- 法人申请的身份证和营业执照是私有材料，不得出现在公开机构档案。

本期分账功能按 `SCOPE-01` 记为 `N/A`，不准备或验证分账配置、比例、提案及收益分配。

## 4. 最小成功链路

### LEG-SMOKE-01 法人申请、批准与原子初始化

1. `L-01` 按总流程完成普通账号基线后，进入“身份认证 → 申请专业身份 → 机构法人”；
2. 按第 3.1 节填写数据并上传三份私有材料，提交后记录 applicationId；
3. 确认待审期间仍只有普通用户能力；
4. `A-01` 在管理端核对申请人与材料后直接批准，本冒烟不执行驳回重提；
5. `L-01` 刷新身份与机构上下文并重新登录一次。

预期：

- 申请为 `APPROVED`，法人专业身份为 `ACTIVE`，基础平台角色仍为 `USER`；
- 同一业务结果创建或恢复已认证机构 `I-01`、一条 `APPROVED` 法人任职和一个机构 USD 钱包；
- `managedInstitutionIds` 只包含 `I-01`，刷新和重登不生成重复机构、任职或钱包；
- 三份私有材料只有申请人与授权管理员可见，不生成公开机构图片。

### LEG-SMOKE-02 编辑机构档案并核对公开页

1. `L-01` 进入“专业管理 → 法人 → 机构档案”；
2. 核对名称、地区、地址和联系电话已由法人申请初始化；
3. 按第 3.2 节填写核心字段并保存；
4. 重新进入页面，确认数据仍然存在；
5. `U-01` 打开 `I-01` 公开机构页。

预期：公开页展示已保存的名称、地址、联系电话、营业时间、介绍、标签、擅长领域、资质文本和公开图片；联系电话仍为 `021-60889026`，登录手机号未改变；营业执照和身份证材料均不可见。

### LEG-SMOKE-03 批准医生和顾问加入机构

本用例按总流程进入两次：`SMOKE-03` 只处理 `D-01`，`SMOKE-04` 再处理 `C-01`；不要求两笔申请同时就绪。

1. `D-01`、`C-01` 分别对 `I-01` 提交一笔 `JOIN`，记录两个 relationshipRequestId；
2. `L-01` 在“专业管理 → 法人 → 机构关系审核”核对目标机构、申请角色和申请人；
3. `L-01` 依次批准医生和顾问申请；
4. 刷新两人的机构上下文、`I-01` 公开成员列表和预约候选。

预期：两笔申请均为 `APPROVED`；医生和顾问各生成一条有效 `I-01` 关系；`D-01` 出现在机构医生范围，`C-01` 出现在公开顾问列表及预约候选；批准医生加入机构不会自动加入任何机构项目。

### LEG-SMOKE-04 批准机构项目

1. `D-01` 基于已批准的 `P-01`，在 `I-01` 按第 3.3 节提交新增机构项目申请；
2. `L-01` 在机构项目审核入口核对项目、价格、医生和目标机构；
3. `L-01` 批准并刷新机构项目详情及医生项目绑定。

预期：`IPJ-01` 与 `D-01` 初始项目绑定在同一业务结果中生效；机构基础价格和医生项目价格均为 `220.00 USD`；项目可供总流程创建 `O-01`，但本分册不重复订单测试。

## 5. 可选生命周期回归

以下项目从默认冒烟移出，需要专项发布、相关代码改动或完整回归时再执行：

| 回归主题 | 覆盖内容 |
|---|---|
| 法人身份异常 | 待审取消诉求由管理员 `REJECT`、驳回后重申、重复申请、材料异常 |
| 机构档案边界 | 全字段格式、图片增删、重复保存、断网重试、只读字段保护 |
| 多机构与越权 | `I-01B/I-02`、跨机构审核、多机构选择与数据隔离 |
| 关系生命周期 | JOIN 撤回/驳回/重复审核，LEAVE、重新加入及强制撤销 |
| 项目生命周期 | 加入已有项目、资料编辑、驳回重提、停用及跨机构审核 |
| 账号与身份终态 | 暂停/恢复、替代法人、管理员撤销法人身份、账号注销边界 |
| 稳定性与界面 | 并发审核、幂等、审计、中英文、窄屏、大字体及不同设备 |

待审法人身份只由管理员 `APPROVE/REJECT`；已生效法人身份只由管理员填写原因后 `REVOKE`。这两条运营规则不改变医生、顾问机构关系由本人发起、目标法人审核的流程。
