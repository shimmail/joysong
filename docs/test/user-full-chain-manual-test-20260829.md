# 普通用户主链路手工联调测试

最后更新：2026-08-29

## 1. 文档定位与公共引用

本分册只验证普通用户独有的前台主链路：注册、登录、普通资料、公开浏览、创建订单、测试支付、确认完成和评价。

以下内容统一以[全角色最小联调测试总流程](README.md)为准，本分册不再重复：

- 隔离环境、安全约束、统一账号和对象清单；
- 法人、医生、顾问、机构和项目的准备顺序；
- 跨角色权限矩阵、公共状态定义和发布阻断；
- 通用双语、排版、网络、并发及服务端权限断言。

执行本分册时复用总流程已经生成的对象 ID，不得重新创建另一套机构、医生、顾问或项目数据。本文冒烟链路只使用 `U-01`；`U-02` 和账号注销属于可选回归。

## 3. 普通用户冒烟主链路

**USR-SMOKE-01 注册、登录与普通资料**

1. 在注册页输入 `+8613900004001`，获取并填写测试验证码，设置测试环境提供的 `${TEST_SHARED_PASSWORD}`；
2. 勾选用户协议和隐私政策，提交后记录 userId；
3. 退出后用手机号和密码登录，再退出并用新验证码登录；
4. 确认三次进入的 userId 相同，账号为 `ACTIVE + USER`，没有专业身份；
5. 按第 2 节填写普通资料并上传公开头像，保存后重新进入；
6. 再次退出和登录，确认资料仍为服务端保存值。

通过条件：只生成一个账号；手机号按 E.164 保存；两种登录方式进入同一账号；普通资料不允许修改账号状态、平台角色或专业身份；私有认证材料不得成为头像。

**USR-SMOKE-02 公开浏览与普通权限**

1. 打开首页、发现和搜索，进入 `I-01`、`D-01`、`IPJ-01` 的公开详情；
2. 核对机构、医生、项目和顾问候选与总流程记录一致；
3. 收藏并取消收藏一个公开对象，刷新页面；
4. 尝试进入法人、医生、顾问的写操作入口。

通过条件：公开内容可读，收藏状态与服务端一致；身份证、执照、资格材料和审核记录不可见；无专业身份时不显示专业写入口，直接请求也必须拒绝。

**USR-SMOKE-03 创建 `O-01`**

1. 从公开项目或医生详情进入预约；
2. 选择 `I-01 + IPJ-01 + D-01 + C-01`；
3. 预约时间设置为执行时刻至少未来 2 天，填写订单备注；
4. 只点击一次提交，记录 orderId、服务端时间、状态和价格快照；
5. 打开订单列表与详情，确认生成的订单记为 `O-01`。

通过条件：机构、项目、医生、顾问、价格和币种均由服务端有效关系及快照确定；订单归属 `U-01`；不存在缺失对象或错误关系；其他普通用户不能读取或操作 `O-01`。

**USR-SMOKE-04 测试/模拟支付与服务开放**

1. 确认当前渠道明确标记为测试或模拟支付；
2. 发起一次测试支付；
3. 记录 paymentId、渠道结果、服务端订单状态和状态日志；
4. 刷新订单详情，确认只有服务端确认成功后才开放服务。

通过条件：没有真实扣款；客户端成功页不能单独改变订单状态；支付后的订单参与方、币种和价格快照不变。重复支付和回调幂等只在可选回归中验证。

**USR-SMOKE-05 完成订单并评价一次**

1. 在 `O-01` 达到允许用户确认完成的状态后，点击一次“确认完成”；
2. 确认订单终态为 `COMPLETED`；
3. 只提交一次五星评价，内容严格使用 `USER-REVIEW-001 流程清晰，服务信息与订单一致，仅用于测试。`；
4. 刷新订单、医生、机构和项目详情，记录评价及统计变化。

通过条件：只有订单本人可以完成和评价；评价绑定 `O-01` 的真实医生、机构和项目；本轮只产生一条五星评价；订单完成后价格和参与方快照不被重写。

## 4. 可选回归，不进入本轮跑通门槛

| 类别 | 可选场景 |
|---|---|
| 注册与认证 | 验证码自动注册、错误或过期验证码、密码边界、并发注册、忘记密码和换绑手机号 |
| 资料与浏览 | 字段长度、头像失败、双端覆盖、空状态、缓存和越权 ID 猜测 |
| 订单 | 缺失字段、过去时间、超长备注、重复点击、取消、退款和支付异常 |
| 评价 | 非完成订单、评分边界、重复或并发评价、修改和删除 |
| 账号状态 | 暂停/恢复普通用户；专业账号的统一暂停回归由管理员分册负责 |
| 账号注销 | 使用专用无商业数据账号 `U-02` 执行预检、二次验证、`ERASED` 和原手机号重新注册 |
| UI | 中英文、Android/iOS、多宽度、大字体、键盘遮挡、相册权限和断网恢复 |

可选回归应按涉及模块单独执行，不得为了让主链路通过而临时加入 P0。
