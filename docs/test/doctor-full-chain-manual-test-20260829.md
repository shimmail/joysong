# 医生角色最小链路手工联调测试

最后更新：2026-08-29

统一入口：[全角色最小联调测试总流程](README.md)。本文只记录医生独有的数据和操作；共同环境、账号准备、管理员审批规则、跨角色顺序、订单通用断言及通过判断均以总流程为准。

## 1. 角色独有目标

使用 `D-01` 跑通以下最短链路：

`普通用户账号已准备 → 提交医生申请 → 管理员批准 → 编辑公开档案 → JOIN I-01 → 提交 P-01 与 IPJ-01 → 查看 O-01`

本册只确认：

- 五份认证材料保持私密，不被复制到公开医生档案；
- 医生身份通过后创建或复用医生档案与 USD 钱包，但不自动加入机构；
- 医生公开联系电话由本人填写，可以与登录手机号不同；
- JOIN 通过后获得 `I-01` 范围，但不会自动获得机构项目绑定；
- 医生只能查看本人 `doctorId` 对应的专业订单。

## 3. 最小执行步骤

### DOC-SMOKE-01 申请并激活医生身份

1. `D-01` 选择医生身份，填写第 2.2 节字段并分别上传五份材料。
2. 提交后记录 `applicationId`，确认状态为 `PENDING`，此时没有医生入口、档案或钱包。
3. 由 `A-01` 按 README 的统一审批步骤批准；`D-01` 刷新或重新登录。
4. 记录 `doctorId`、医生钱包 ID 和当前专业角色。

预期：医生角色为 `ACTIVE`；医生档案和唯一 USD 钱包已创建或复用；基础平台角色仍为普通用户；没有机构关系和项目绑定。

### DOC-SMOKE-02 编辑并公开医生档案

1. 按第 2.3 节保存公开档案并重新进入页面。
2. 使用 `U-01` 打开医生公开详情。

预期：公开字段持久化；登录手机号不变；五份私密材料、证件号码及申请理由不公开；两张公开展示材料不得被标记为平台核验材料。

### DOC-SMOKE-03 加入 `I-01`

1. `D-01` 提交 `JOIN I-01`，说明填写 `DOC-E2E-001 申请加入测试机构开展执业联调`。
2. 待审时确认当前关系仍为 `NONE`，不能提前选择 `I-01` 发起机构业务。
3. 由 `L-01` 按 README 的统一关系审核步骤批准。

预期：申请和关系均为 `APPROVED`，医生机构范围包含 `I-01`；医生仍无机构管理权，也没有自动生成的项目绑定。

### DOC-SMOKE-04 提交 `P-01` 与 `IPJ-01`

1. `D-01` 按第 2.3 节提交平台项目 `P-01`，等待 `A-01` 批准。
2. 在 `P-01` 可用后，向 `I-01` 提交新增机构项目 `IPJ-01`，等待 `L-01` 批准。
3. 记录 `projectId`、`institutionProjectId` 和医生项目绑定 ID。

预期：`P-01` 参考价为 `200.00 USD`；`IPJ-01` 的机构基础价和医生项目价均为 `220.00 USD`；医生绑定只在机构项目批准后出现。

### DOC-SMOKE-05 查看 `O-01`

1. 等待 `U-01` 按 README 使用 `I-01 + IPJ-01 + D-01 + C-01` 创建 `O-01`。
2. `D-01` 从医生专业订单入口查看列表和详情。
3. 使用另一医生身份或普通用户身份尝试进入医生专业订单详情。

预期：`D-01` 能看到快照中 doctorId 为本人的 `O-01`；非目标医生不能查看或处理。创建、支付、完成及评价的通用断言只在 README 和用户分册执行一次。

## 4. 角色独有检查点

| 检查点 | 通过标准 |
|---|---|
| 私密材料 | 仅授权审核可见，不进入公开响应或公开图片 |
| 初始能力 | 身份通过不自动加入机构或项目 |
| 档案权限 | 仅有效医生本人可以更新；平台统计和认证状态不可由页面修改 |
| 机构权限 | JOIN 待审不提前授权；通过后仅增加可见/执业范围，不增加法人权限 |
| 项目权限 | 只能为有效机构关系提交申请，不能直接生成正式项目 |
| 订单权限 | 只读取本人医生订单，关系变化不改写历史订单快照 |

## 5. 可选回归

下列场景不阻塞最小链路；需要专项回归时使用独立可恢复夹具，不破坏 `D-01/O-01`：

| 场景 | 最小检查 |
|---|---|
| 驳回与重申 | 使用 `D-R01` 验证旧驳回记录保留、新申请独立、档案和钱包不重复 |
| 字段与材料边界 | 缺字段、缺材料、错误文件用途、他人 fileId、超限文件均不得创建申请 |
| 退出与重新加入 | LEAVE 批准后移除机构范围；重新 JOIN 不自动恢复已清理的项目绑定 |
| 暂停与恢复 | 暂停后从公开入口及新预约候选移除；恢复后复用身份、关系和绑定 |
| 身份撤销与重认 | 撤销后专业权限关闭、关系清理；重认复用档案和钱包但不恢复机构关系 |
| 越权与会话失效 | 页面打开后角色或关系失效，下一次写请求立即拒绝 |
