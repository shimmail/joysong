# 医美顾问角色最小链路手工联调测试

最后更新：2026-08-29

统一入口：[全角色最小联调测试总流程](README.md)。本文只记录医美顾问（代码角色 `CONSULTANT`，下文简称“顾问”）独有的数据和操作；共同环境、账号准备、管理员审批规则、跨角色顺序和订单通用断言均以总流程为准。

## 1. 角色独有目标

使用 `C-01` 跑通以下最短链路：

`普通用户账号及公开资料已准备 → 提交顾问申请 → 管理员批准 → 核对角色与钱包 → JOIN I-01 → 进入公开候选 → 分配到 O-01`

本册只确认：

- 三份认证材料及申请中的真实信息保持私密；
- 顾问身份通过后创建或复用唯一 USD 钱包，但不创建顾问专业档案；
- 顾问公开名称和头像来自普通用户资料；
- JOIN 通过后才进入 `I-01` 公开顾问列表和新预约候选；
- 顾问项目目录只读，不能获得机构、项目或医生权限；
- `O-01` 可以关联 `C-01`，但当前没有独立顾问订单工作台和完整顾问履约入口。

## 3. 最小执行步骤

### CON-SMOKE-01 申请并激活顾问身份

1. 先按第 2.2 节保存 `C-01` 普通资料。
2. 选择顾问身份，填写第 2.3 节字段并分别上传三份材料。
3. 提交后记录 `applicationId`，确认状态为 `PENDING`，此时没有顾问角色或钱包。
4. 由 `A-01` 按 README 的统一审批步骤批准；`C-01` 刷新或重新登录。

预期：顾问角色为 `ACTIVE`，基础平台角色仍为普通用户；创建或复用唯一 `CONSULTANT + USD` 钱包；没有机构关系，也没有顾问专业档案。

### CON-SMOKE-02 核对专业能力边界

1. 打开顾问专业管理入口、机构关系、项目目录和普通钱包。
2. 尝试查找顾问档案编辑、项目新增/编辑、医生档案和机构管理入口。

预期：顾问可使用机构关系、只读项目目录和本人顾问钱包；不存在顾问专业档案；不得取得项目写权限、医生权限或法人权限。

### CON-SMOKE-03 加入 `I-01`

1. `C-01` 按第 2.4 节提交 `JOIN I-01` 并记录 `requestId`。
2. 待审期间检查当前机构、公开顾问列表和预约候选。
3. 由 `L-01` 按 README 的统一关系审核步骤批准。

预期：待审时关系为 `NONE` 且不进入候选；批准后申请和关系均为 `APPROVED`，顾问机构范围包含 `I-01`，但仍没有机构管理权。

### CON-SMOKE-04 验证公开顾问候选

1. 使用 `U-01` 打开 `I-01` 公开顾问列表和使用 `IPJ-01` 的预约页。
2. 搜索并选择 `C-01`，同时检查公开响应字段。

预期：展示名称为 `顾问测试甲`，头像来自普通公开资料；真实姓名、申请联系电话、证件号码、从业经历、申请理由、材料说明和私密文件均不出现。

### CON-SMOKE-05 关联 `O-01` 并记录履约边界

1. `U-01` 按 README 使用 `I-01 + IPJ-01 + D-01 + C-01` 创建 `O-01`。
2. 核对订单快照中的 consultantId 指向 `C-01`，并确认公开候选与订单选择一致。
3. 在顾问专业管理、普通订单和消息入口检查顾问可用的订单能力。

预期：有效关系的 `C-01` 可以被选择并写入 `O-01`；无关系或关系待审的顾问不能被选择。订单创建、支付、完成和评价的共享冒烟可以按 README 判定，但当前没有独立顾问订单工作台和完整顾问履约入口，因此不得宣称用户、医生、顾问三方履约已形成完整闭环。

## 4. 角色独有检查点

| 检查点 | 通过标准 |
|---|---|
| 私密申请 | 六个申请字段和三份材料仅授权审核可见 |
| 角色初始化 | 身份通过只激活顾问角色并创建或复用一个 USD 钱包 |
| 专业档案 | 系统不创建顾问专业档案，不用普通资料冒充档案 |
| 公开候选 | 仅有效账号、有效顾问身份和 `APPROVED` 机构关系进入候选 |
| 信息来源 | 候选名称和头像来自普通资料，不来自实名申请 |
| 权限范围 | 顾问无机构管理、项目写入、医生或管理员权限 |
| 交易结论 | `O-01` 交易冒烟可按共享流程记录；完整三方履约继续标记为能力限制 |

## 5. 可选回归

下列场景不阻塞最小链路；需要专项回归时使用独立可恢复夹具，不破坏 `C-01/O-01`：

| 场景 | 最小检查 |
|---|---|
| 驳回与重申 | 驳回原因可见，新申请独立，顾问角色和钱包不提前创建 |
| 字段与材料边界 | 缺字段、缺材料、错误文件用途、他人 fileId、超限文件均不得创建申请 |
| 多机构 | 加入第二机构后两条 membershipId 独立，不能取得任一机构管理权 |
| 退出机构 | LEAVE 批准后移出目标机构候选，其他有效关系不受影响 |
| 暂停与恢复 | 暂停后移出公开列表和新预约候选；恢复后复用原身份和关系 |
| 单关系强制撤销 | 只移除目标机构关系，不改变顾问身份和普通资料 |
| 身份撤销与重认 | 撤销关闭顾问权限并清理关系；重认复用钱包但不自动恢复关系 |
