# 平台管理员主链路手工联调测试

最后更新：2026-08-29

## 1. 文档定位与公共引用

本分册只验证平台管理员在本轮跑通流程中的独有操作：管理员登录、审批三类专业身份、审批平台项目 `P-01`、查看全局订单 `O-01`。

以下内容统一以[全角色最小联调测试总流程](README.md)为准，本分册不再重复：

- 隔离环境、统一账号、机构和业务对象清单；
- 法人、医生、顾问的申请字段、材料及申请人侧页面步骤；
- 机构关系和机构项目由目标机构法人执行的标准审核链路；
- 通用状态、权限矩阵、UI 检查、发布阻断和总放行标准。

管理员只处理其他角色分册已经提交并记录 ID 的对象。不得在本分册重新注册申请人、重复提交申请，或直接改库跳过正常前置。

## 3. 平台管理员冒烟主链路

**ADM-SMOKE-01 `A-01` 登录管理端**

1. 打开管理端登录页；
2. 输入手机号 `13800009001` 和测试环境提供的 `${TEST_ADMIN_PASSWORD}`；
3. 登录后记录管理员 userId、平台角色和会话时间；
4. 打开用户、身份审核、项目审核和订单菜单。

通过条件：仅管理登录入口成功；返回平台角色 `ADMIN`；不存在医生、顾问或法人身份的自动附加；密码不出现在 URL、页面日志或错误信息中。

**ADM-SMOKE-02 审批法人、医生和顾问身份**

三笔申请分别在 `SMOKE-02`、`SMOKE-03`、`SMOKE-04` 到达时执行，不创建额外驳回或重提分支：

1. 按 applicationId 打开 `L-01` 法人申请，核对申请字段和三份材料，填写法人审批说明并批准；
2. 按 applicationId 打开 `D-01` 医生申请，核对申请字段和五份材料，填写医生审批说明并批准；
3. 按 applicationId 打开 `C-01` 顾问申请，核对申请字段和三份材料，填写顾问审批说明并批准；
4. 刷新身份申请、职业身份和用户详情，记录 reviewer、reviewedAt 和角色状态；
5. 分别返回对应角色分册核对初始化结果。

通过条件：

- 三笔申请均从 `PENDING` 变为 `APPROVED`，三类专业角色分别为 `ACTIVE`，平台角色仍为 `USER`；
- 法人审批创建或恢复已认证机构、法人任职和机构钱包；
- 医生审批创建或恢复医生档案和医生钱包，但不自动加入机构或机构项目；
- 顾问审批创建或复用顾问钱包，但不创建顾问专业档案、不自动加入机构；
- 私有材料只通过受控预览读取，不进入公开页面或永久公开地址；
- 每笔审批只产生一次业务副作用。

**ADM-SMOKE-03 审批平台项目 `P-01`**

1. 进入平台项目申请审核，按 project applicationId 找到 `D-01` 提交的 `P-01`；
2. 核对项目名称、分类、说明、标签、参考价格、币种和申请人；
3. 填写 `ADMIN-PROJECT-APPROVE-001 平台项目资料核验通过` 并批准；
4. 刷新申请和正式项目列表，记录正式 projectId。

通过条件：申请变为 `APPROVED`；只生成一个正式 `P-01`；项目字段与批准快照一致；本步骤不创建机构项目或医生项目绑定，后续由医生和目标机构法人完成。

**ADM-SMOKE-04 查看全局订单 `O-01`**

1. 等待用户分册创建 `O-01` 后，按 orderId 在订单管理中搜索；
2. 对照用户分册证据核对用户、机构、项目、医生、顾问、金额、币种和至少未来 2 天的预约时间；
3. 查看支付记录和订单状态日志；
4. 在用户确认完成并评价后刷新，核对 `COMPLETED` 和唯一评价结果；
5. 本轮只读查看，不执行删除、改价或人工改状态。

通过条件：管理端展示与服务端订单快照一致；支付状态有服务端记录；普通用户只能查看本人订单；管理员查看不会改变订单、评价或任何参与方数据。

## 4. 可选回归与已知限制

| 类别 | 可选场景 |
|---|---|
| 管理员生命周期 | `A-02` 准备、提升、独立登录、暂停、恢复、降权和改密 |
| 管理员保护 | Bootstrap 保护、最后一个可用管理员保护、并发角色变更 |
| 身份审核 | 驳回与重提、申请人取消诉求代办、重复审核、两名管理员并发审核 |
| 账号状态 | 暂停/恢复普通用户、医生和顾问，并验证公开隐藏及新订单拒绝 |
| 关系与项目 | 平台人工覆盖、单个关系强制撤销、机构项目全局投影和兜底审核 |
| 专业终态 | 管理员撤销法人、医生或顾问专业身份，以及撤销后的权限和历史数据 |
| 管理端 UI | 多浏览器、窄窗口、缩放、大字体、长文本、材料预览和断网恢复 |

已知限制 `ADMIN-BLOCK-05`：待审专业身份申请在账号已暂停时仍可能被批准。规则和服务端校验未统一前，该场景不得记为通过；本轮主链只审批状态为 `ACTIVE` 的申请人。

可选回归不影响本文四个主步骤的执行记录，但跨角色发布门槛仍以 `README.md` 为准。
